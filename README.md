# Navalha

MVP de SaaS para gestão de barbearias desenvolvido com Next.js, TypeScript e Tailwind CSS.

## Executar

```bash
npm run dev
```

Acesse:

- `/` — landing page
- `/dashboard` — painel administrativo com dados mockados

## Recursos

- Visão geral e indicadores
- Agenda diária
- Estrutura visual para clientes, serviços, financeiro e equipe
- Layout responsivo em português do Brasil
